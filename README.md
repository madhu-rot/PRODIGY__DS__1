🌍 World Population Analysis & Visualization
Prodigy InfoTech – Data Science Internship | Task 01
📌 Project Overview
This project focuses on analyzing and visualizing global population data using Python and Microsoft Power BI.
The objective of this task is to create visualizations such as bar charts and histograms to understand population distribution across different countries and analyze population growth over time.
The project uses population data from the World Bank, covering the years 1960–2025.
🎯 Objectives
Analyze global population data.
Clean and preprocess the dataset.
Explore population distribution across countries.
Identify the most populated countries.
Visualize population trends over time.
Create an interactive and informative Power BI dashboard.
📊 Dataset
Source: World Bank – World Development Indicators
Indicator: Population, Total (SP.POP.TOTL)
Dataset: World Bank Population Data
Time Period: 1960–2025
The dataset contains country names, country codes, and annual population figures.

🧹 Data Cleaning & Preprocessing
The following steps were performed:
Loaded the original World Bank population dataset.
Inspected the dataset and its structure.
Cleaned and prepared the population data.
Restructured the year columns into a suitable format for analysis.
Handled missing and invalid values.
